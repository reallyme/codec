# Codec contract

The public APIs and protobuf schemas shipped with each release define its
supported formats, message shapes and errors. Use matching package versions
when exchanging serialized operations between languages.

Repository maintenance follows the ReallyMe
[engineering rules](https://github.com/reallyme/.github/blob/main/ENGINEERING_PHILOSOPHY.md)
and [architecture](https://github.com/reallyme/.github/blob/main/ARCHITECTURE.md).
